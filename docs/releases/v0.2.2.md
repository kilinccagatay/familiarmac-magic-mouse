# FamiliarMac Magic Mouse 0.2.2

One-finger swipes now continue reporting movement when the finger reverses through the recognition threshold. Consumers can smoothly reverse or cancel native page navigation without a gap in progress events.

- Existing two-finger gestures, double taps and physical-click cancellation are preserved.
- All 20 parser and gesture tests pass, including the new reversal regression test.
- Chrome input delivery belongs to FamiliarMac; this library remains passive and emits no input events.
