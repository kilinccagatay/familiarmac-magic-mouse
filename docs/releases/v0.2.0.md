# FamiliarMac Magic Mouse 0.2.0

- Recognize one-finger double taps and horizontal swipes while preserving vertical scrolling.
- Include final displacement and scale in gesture completion; cancel invalid or mixed-contact sequences.
- Decode the original Magic Mouse’s interleaved standard pointer reports without losing touch state; physical clicks cancel tap recognition.
- Expose contact counts and timestamps for desktop adapters.

Original Magic Mouse hardware checks confirmed double-tap, page navigation, document zoom and continuous workspace switching through FamiliarMac. Lightning and USB-C models remain parser-tested only. Pinch is an event API without a FamiliarMac desktop action.

The library remains passive and MIT-licensed. MouseTouch, magic-mouse-wayland-gestures and magic-mouse-gestures attribution and original licenses are included. Smart Zoom in FamiliarMac uses application zoom commands, not macOS semantic content framing.
