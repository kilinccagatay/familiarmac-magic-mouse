# FamiliarMac Magic Mouse 0.2.1

- Recognize two-finger horizontal swipes earlier while preserving tap, vertical-scroll and pinch arbitration.
- Accumulate per-contact movement incrementally so long swipes retain their direction across coordinate wrap and deliberate reversals.
- Preserve continuous positions for long pinch gestures.

All 19 parser and gesture regression tests pass, including long swipes, wraparound, reversals and earlier horizontal recognition. The fixes were also exercised through FamiliarMac on the original Magic Mouse; Lightning and USB-C models remain parser-tested only.

This release updates the passive gesture library. Desktop-service click handling, session-query performance and menu-bar animation fixes belong to FamiliarMac, not this library. Existing upstream attribution, MIT licensing and original license notices are unchanged.
